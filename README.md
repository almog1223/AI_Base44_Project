# חברים על ארבע: מערכת ניהול חילוץ, טיפול ואימוץ

פרויקט גמר בקורס Vibe Coding & Base44 (מקרה 4 מבנק הבעיות).

- **אפליקציה:** https://four-paw-pals.base44.app
- **קוד ומסמכים:** https://github.com/almog1223/AI_Base44_Project

## מטרת הפרוייקט
אפליקציה לעמותת חילוץ שמרכזת כרטיס לכל בעל חיים: מיקום, תיק רפואי, אומנה והתנהגות. המערכת חוסמת יציאה של בעל חיים בטיפול, שולחת תזכורות לחיסונים, וסוכן AI מדרג בקשות אימוץ.

## מתודולוגיה
הפרוייקט מפותח במתודולוגיית **SDD (Spec-Driven Development)**: כל פיצ'ר מתחיל במפרט כתוב, ממשיך לתוכנית ולמשימות, ורק אז למימוש.

## עבודה עם סוכנים
הפרוייקט מיועד לעבודה עם מספר סוכנים. כל ההוראות, ההחלטות וההקשר נשמרים בקבצים ולא בצ'אט.
ההנחיות לסוכנים נמצאות ב-[AGENTS.md](AGENTS.md).
