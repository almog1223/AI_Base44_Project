## מתודולוגיה
הפרוייקט מפותח במתודולוגיית **SDD (Spec-Driven Development)**: כל פיצ'ר מתחיל במפרט כתוב, ממשיך לתוכנית ולמשימות, ורק אז למימוש.

## עבודה עם סוכנים
הפרוייקט מיועד לעבודה עם מספר סוכנים. כל ההוראות, ההחלטות וההקשר נשמרים בקבצים ולא בצ'אט.
ההנחיות לסוכנים נמצאות ב-[AGENTS.md](AGENTS.md).
